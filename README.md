# Tiny Theme (Eleventy 3.1.2)

A deliberately minimal Eleventy site + blog using ESM and Luxon.

## Quick start

```bash
npm install
npm run start
```

Build output goes to `_site/`.

## Features

- ESM config (`eleventy.config.mjs`)
- Luxon-based date filters (no Nunjucks date filter errors)
- Blog with pagination
- Tags with tag index pages
- RSS feed (`/feed.xml`)
- Sitemap (`/sitemap.xml`)
- `robots.txt` and `humans.txt`
- Post layout with previous/next arrow buttons
